## Training

Use the following command to train the model:

```bash
python main.py --model reg_mixer_attnpl_t --mode train
python main.py --model clf_mixer_attnpl_t --mode train 
```

To use Optuna for hyperparameter tuning (set the hyperparameter ranges in the main file), set `--mode` to `optuna`:

```bash
python main.py --model reg_mixer_attnpl_t --mode train
python main.py --model clf_mixer_attnpl_t --mode train
```

## Testing

Use the following command to test the model:

```bash
python main.py --model FGCN_f/FGCN/TGCN --mode test --config <path_to_config_file> [--checkpoint <path_to_checkpoint_file>]
```

- If `--checkpoint` is not specified, the most recently trained model will be used by default.

## Logs

Use TensorBoard to view training logs:

```bash
tensorboard --logdir <tensorboard_folder_in_checkpoint_directory> --port <port_number>
```

The `test.ipynb` file can be used to locate checkpoint files under specific conditions.
