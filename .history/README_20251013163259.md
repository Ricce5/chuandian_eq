## Installation
The GPU must support `flash_attn` and `mamba_ssm`.
1. install pytorch
2. installl flash_attn
https://github.com/Dao-AILab/flash-attention/releases
3. install causal_conv1d
https://github.com/Dao-AILab/causal-conv1d/releases
4. install mamba_ssm
https://github.com/state-spaces/mamba/releases

## Training
Use the following command to train the model:

```bash
python main.py --model reg_mixer_attnpl_t/clf_mixer_attnpl_t/mixer_tpp/etas/rtpp/etas --mode train --config <path_to_config_file>
```

## Testing

Use the following command to test the model:

```bash
python main.py --model reg_mixer_attnpl_t/clf_mixer_attnpl_t/mixer_tpp/etas/rtpp/etas --mode train --config <path_to_config_file>
```

- If `--checkpoint` is not specified, the most recently trained model will be used by default.

## Logs

Use TensorBoard to view training logs:

```bash
tensorboard --logdir <tensorboard_folder_in_checkpoint_directory> --port <port_number>
```
