# src Layout

This directory stores only project source code.

## Modules

- `src/catalogs`: Catalog readers, converters, and dataset-specific loaders.
- `src/data`: Dataset objects, sequence builders, preprocessing, and batch utilities.
- `src/distributions`: Statistical distributions and mixture components.
- `src/features`: Feature engineering and spatial/temporal feature helpers.
- `src/models`: Model definitions and model building blocks.
- `src/train`: Training loops, trainer logic, and train-step implementations.
- `src/utils`: Shared utility functions used across the project.
